# 菌絲體記

閱：[简体中文](README_zh-Hans.md) · [English](README.md)

本文僅陳理念之梗概，未贅術理。會心者自明。

自赤魃僭政，竊據神州，指鹿蠱心，箠楚黎庶。言路壅塞，萬馬齊瘖。文脈之存，本欲啟民德、開民智，然民國肇建，曇花一現，旋即凋零。今帝制穢土轉生，號曰「新華」，實乃冠冕之偽耳！冊籍刊佈皆淪箝制——華文蒙垢，舌端劫灰，斯乃華夏之至悲也！

更有甚者，科藝雖設，盡化囚綱：語模初興，羽翼未豐，便加黨管之枷；尚未利民促建，即充作弄輿之污役。故此器之國產者，雖精巧於數理，然於文史哲政，皆若鐐足而舞，豈得不畸？非機器之不敏，實朽制錮之，自斃而已。

彼僭據之徒盤據神州，歲歷人壽，所欠血債文債，早罄竹難書，天理斷難容也。

---

有鑑於此，吾儕創設此法，名曰「菌絲體」。此法取巧於訂閱源制，輔以混淆、偽裝、重密之制，意在假公網之便，行瞞天過海之實。

其術託身於檔案分享之平臺，謂之「壤」；「壤」中生「核」，訂閱源之本體也，內藏數「果」，一果即一獨立之篇。有「播者」焉，職在栽培：育「核」於「壤」，加密而署之，可飾以常文，若熱門之復刻，匿於支分暗庫中；「核」既入「壤」，乃結「孢」。「孢」者，溯「核」之樞也。一「核」唯生一正鏈，蘊藏壤址與驗鑰，衍而為「孢」。孢之分身無限，複製再廣傳，乃其自生之理也。有「採者」拾「孢」循跡，遣「絲」以溯，於「壤」得「核」，驗其署而解其密，遂收其新「果」。其驗之所憑，唯「孢」中蘊藏之公鑰，不假外求。

須知此法非避役之神盾，亦非匿跡之術。採者之網跡，運販與平臺皆可窺之，若欲絕跡於彼之法眼，仍須仰賴代理之屬。然其真所爭者，時與費也；所先保者，播者也，蓋播者之危遠甚於採者，護源即護流，護核即保絲。俾彼搜捕之鷹犬，徒勞於蟻穴；索源之成本，重若泰山。此即「瞞天過海」之微旨。

斯術雖重密保安，然平臺之取用猶須謹慎。峻法之域，流異之跡，或奸人剖析孢子得其所託而告於平臺，皆惹平臺注目倉庫，首當其衝者，播者也；至於窮究採者與否，端視事態輕重。寬簡之域則免此患，惟網跡稍阻耳。

孢之公私，定其所用：公者，所載惟公；私者，可託密語。然同鑰共群，無逐人褫奪之權，一洩則全局皆洩。孢之形態，僅將儲址公鑰混淆而已，非加密也——其鑰本為公開之驗證鑰，能讀此鏈者皆可逆解。所禦者，窺伺之徒與網絡爬蟲耳，非以拒堅敵也。至若私鑰之守，乃播者之專責：私鑰一失，菌核不復可恃，當速止更新，另闢新核以引採者。

---

吾等之志，豈僅在於一技之傳、一文之遞？實欲借此隱微之網，存薪火於將熄，致清算於來日：

**一曰清算血債，瓦解苛政。** 赤魃盤踞，殘害生靈，荼毒思想。吾等欲以菌絲體，暗傳禁聞，播撒真史，灌溉枯槁之民心，使民知真相、明是非。高墻雖峻，難遏地底無形之根。

**二曰克紹箕裘，憲政安邦。** 吾儕矢志還政於民。上繼民國《四六憲法》之正統，使五權分立、三民之規重光於九州；下承《零八憲章》之遺願，使自由、人權、民主、憲政之光，普照於華夏。

**三曰解放個體，復歸人文。** 破除「黨管學術」之桎梏，釋放各業產能。使學無束縛，器亦有魂。使閹豎之學永絕，而華文得迎無欺之復興。

涓埃匯而江河成，菌絲連而林莽興。彼雖有高墻巨壁、百般箝制，安能防地底無形之網乎？待到春雷震動，菌絲破土，彼僭政之危樓，必隨之傾覆。

謹以此記，告我同袍，共迎復旦之晨曦。
